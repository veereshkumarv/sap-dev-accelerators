## Prerequisites

- Authorization object **ZSD_ORDER** with field `ACTVT` exists (create it in ADT if needed)

- Package **ZSD_ORDERS** (created by abapGit from `src/package.devc.xml`).

## Import and activate

1. abapGit (ADT plug-in or gCTS): link this repository to package ZSD_ORDERS and pull.
2. Activate all objects (mass activation).
3. Open service binding **ZUI_SD_ORDER_O4** in ADT and choose *Publish*.
4. Run ABAP Unit on **ZBP_R_SD_ORDER** and ATC with the clean-core check variant.
